The Desk Suite is the page family inside the Fintheon sidebar. **Lab** is the default page. The same sidebar stays in place as users move between surfaces, so history, search, account controls, and return paths remain familiar.

## Page order

| Page | Purpose |
| --- | --- |
| **Lab** | The main investigation surface. Start from a market target, create a governed analysis session, and work with the stage, context, and artifacts that support a decision. |
| **Presentations** | The user-facing War Room. Turn a live thesis into a structured presentation of evidence, current context, and conclusions. |
| **Clips** | Save and reuse short, meaningful pieces of research or market material inside the Desk workflow. |
| **NarrativeFlow** | Connect evidence, research, charts, and notes into the market narrative that explains what matters and why. |
| **Chat** | The conversation home for direct chats, channels, rooms, and permanent searchable history. |
| **Scouts** | Scheduled market watches and recurring research. When its runtime is unavailable, it must say so plainly and preserve the user’s state. |
| **Settings** | The route into the unified Agentic Desk and Context settings. |

## Fixed and supporting surfaces

Some parts of Desk support every page rather than acting as another tab.

- **CAO** remains a protected Desk surface for governed analyst work.
- **Channels** live within Chat. Selecting one makes the room the central work surface.
- **DeskMap** connects room context, shared artifacts, member presence, and agent actions.
- **QuantComposer** anchors analysis and annotations to real artifacts and charts.
- **Dynamic Islands** surface Desk, Forum, or Presentation activity only when it matters. They never become a permanent third column.

## A single visual system

Each page can have its own list, quick actions, counts, and controls. It still uses the same sidebar size, account area, search affordance, navigation behavior, and visual language. The Desk does not add a second permanent sidebar or an always-open details column.
